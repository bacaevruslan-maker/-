# Монтаж экспертных Reels врача-нефролога

Проект для сборки вертикальных экспертных видео из предоставленных пользователем исходников.

## Подготовка окружения

В поле «Скрипт установки» облачного окружения укажите:

```bash
bash scripts/setup.sh
```

Скрипт проверяет Python 3, FFmpeg/FFprobe, кодировщики H.264/AAC и поддержку субтитров ASS. Если FFmpeg или шрифты отсутствуют, он пытается установить системные пакеты через apt-get. Для этого нужны доступ к пакетным репозиториям и права установки. При отсутствии необходимых возможностей скрипт завершится с понятной ошибкой.

Скрипт не устанавливает модель распознавания речи. Перед монтажом агент отдельно проверяет доступные средства расшифровки. Автоматическая расшифровка может потребовать дополнительных зависимостей и загрузки модели.

## Работа

1. Предоставьте исходники в рабочее окружение в каталог `input/`.
2. Укажите тему и обязательные фрагменты; по умолчанию — русский язык, вертикальное видео около 30 секунд.
3. Попросите агента выполнить монтаж по `AGENTS.md` и `config/reels.json`.
4. Заберите результат из `output/`.

Облачное окружение не получает автоматически доступ к папке на вашем компьютере. Передавайте исходники отдельно. Исходные видео и результаты исключены из Git; для их сохранности используйте отдельное хранилище.

## Выходные файлы

- `output/reels_final.mp4` — ролик с субтитрами и надписями.
- `output/reels_clean.mp4` — тот же монтаж без субтитров и графики.
- `output/subtitles.srt` — проверенные субтитры.
- `output/description.txt` — описание и медицинские источники.
- `output/edit-notes.md` — использованные фрагменты, проверки и ограничения.

Скрипты повторной сборки храните в `scripts/`; ссылки на исходники делайте относительными. Сами медиафайлы не коммитьте.
